# Answer the question that was asked

**14 questions in this bank are decided purely by whether the option addresses
the question's actual ask.** The walkthroughs say this out loud, which is why it
is worth internalising.

## How it looks

Every option is defensible engineering. Only one addresses what the question
demands — improve *performance*, reduce *rollbacks*, cut *cost*, satisfy a
*compliance* clause. The distractor solves a real but different problem.

> [ASR] It doesn't improve the performance of the existing system as the
> question asks. — walkthrough for **Q34**

> [ASR] This would create a huge amount of operational work which is the
> opposite of what the question asks for. — walkthrough for **Q32**

## How to avoid it

1. Underline the verb and the constraint in the stem before comparing options
   ("*reduce* unplanned rollbacks", "*minimise* cost", "*encrypt* at rest").
2. For each option ask: does this serve that verb, or a neighbouring concern?
3. A statement that is true about GCP but irrelevant to the ask is exactly what
   the exam uses as a distractor — being technically correct is not sufficient.

This trap is what makes the cheap-but-irrelevant option in [[cost-first]] and the
self-managed-but-workable option in [[operational-overhead]] attractive, so read
those two together with this page.
